## Where things live

- `writeups/` lab and CTF writeups, one file each
- `projects/` bigger builds (scanners, SIEM lab, honeypot, audits)
- `notes/` what I learned, by topic
- `weekly-log/` one short entry every week
- `templates/` copy these to start a new writeup, log or project
- `roadmap/` the tickable roadmap site

## Rules I follow

1. I only test systems I own or have written permission to test.
2. I never publish flags, passwords, tokens or keys.
3. I do not publish writeups of active Hack The Box machines.
4. Everything is in my own words. If I learned it from someone, I credit them.
