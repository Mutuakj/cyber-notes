Sync settings and setup guide

Progress is saved to progress.json in your GitHub repo. Without a token the page is read only for synced data and saves on this device only.

One time setup

  1. On GitHub create a new public repository, for example cyber-roadmap.
  2. Upload this file to it as index.html.
  3. Repo Settings, Pages, deploy from branch main, folder / (root). Your site appears at https://USERNAME.github.io/REPO/.
  4. GitHub profile, Settings, Developer settings, Personal access tokens, Fine grained tokens. Select only this repo and set Contents to Read and write.
  5. Open your site, paste the token here and press Save and sync. Your first tick creates progress.json.
  6. On any other PC open the same URL and paste the token again. Press Disconnect on shared computers.

Never put the token inside the code or commit it. If it leaks, delete it on GitHub and make a new one.
